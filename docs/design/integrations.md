# Integrations redesign

Mode: Operate. Herm's existing native typography, theme roles, and action components remain authoritative.

## Direction contract

THESIS: An integration manager, not a wall of interchangeable tiles. Use top category navigation, a responsive card grid, and a nonmodal detail pane.

OWN-WORLD: Shared Dock surfaces and status colors, system typography, shared themed cards, quiet selected contours. No new feature palette. Each card groups status and source with the item identity.

STORY: Choose a capability or connection category, search and filter its actual inventory, then open one item to inspect or configure it. Hermes remains authoritative; unavailable state stays honest.

FIRST VIEWPORT: Six category tabs span the top. A category title, purpose, inventory summary, search and scope controls precede a full-width inventory. Cards show names, descriptions, status, and source together; connector catalog logos and platform glyphs identify services where available. Details open beside the grid; small windows devote the work area to the detail.

FORM: Native integration gallery with a resizable detail pane. seed: none (launcher unavailable). No new visual identity or image assets.

FINISH: Render every category, wide and narrow, Light, Dark, Glass and Monochrome; inspect real wrapping and empty/recovery states; pass focused tests and make guard; update the Integrations surface specification.
