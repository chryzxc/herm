# Security policy

## Reporting a vulnerability

Please do not publish vulnerability details, proof-of-concept code, credentials,
or sensitive logs in an issue or pull request.

This repository does not currently have a verified private reporting channel.
If you need to report a vulnerability, you can [open an issue](https://github.com/chryzxc/herm/issues/new)
asking a maintainer how to contact them privately. Keep the request free of
vulnerability details and sensitive information. A private channel and a
response are not guaranteed; wait for a suitable private channel before
sharing details. Do not include secrets even in a report.

For non-security bugs, use the regular issue tracker. Herm is a client for
Hermes Agent; issues in the upstream runtime should be reported to the upstream
project through its own security process.
